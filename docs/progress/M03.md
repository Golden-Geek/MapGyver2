# M03 progress - control service and remote contract

Status: in_progress, independent portable implementation. M02/M01 qualification
remains open; M03 cannot be completed ahead of those dependencies.

## M03.C01 reliable session core

ControlService now binds client/session/service identity, validates strict
versioned request envelopes and routes structural/parameter/undo/redo operations
through the authoritative controller/registry. It implements expected authored
revisions, single editing ownership, observer access and explicit ownership
generation/transfer/release. Accepted replies identify authored publication only;
native rendering and persistence remain unavailable with explicit reasons and
null applied/saved revisions. Non-null show scheduling is rejected visibly.

Sequence-scoped terminal response caches support reconnect/lost-ack retries;
payload mismatches, gaps and expired sequences never execute. Both accepted and
rejected outcomes are retained. Cache eviction preserves sequence watermarks;
session retention is bounded by a monotonic control-clock deadline and does not
evict retained identities early under pressure. Service restarts change identity.
Subscription cursors recover bounded journal batches or a complete current
snapshot when older events were evicted. No unbounded subscriber queue exists.
Serialized snapshot, response/cache and journal reservations precede publication;
over-budget state changes roll back instead of becoming uninspectable.

The initial protocol test exposed a stale-revision reply using the registry's
internal stale_snapshot code. An explicit service-boundary authored revision
check now returns revision_conflict consistently; assertions were not weakened.
Final Windows Debug/Release wrappers each pass all twelve contracts on 25de351
plus dirty=true, including byte-budget reply eviction, expired mutation replay
refusal, request size rejection and remote structural-batch rollback.
[Detailed contract](../../libs/protocol/README.md). Clean committed/hosted checks
follow after commit.

This slice is portable in-process control/session evidence. It does not implement
or qualify named-pipe IO, remote sockets, OSCQuery, actual native applied outcomes,
durable saving, UI/preview or managed-app launch deduplication. Those remain open;
the next C01 slice connects the real engine through bounded Windows named-pipe IO.

## M03.C03 local reliable browser and static editor

The capability-bound `/control` WebSocket route reuses ControlService's exact
hello/envelope/cache/ownership/subscription contract. Credentials use actual
checked OS CSPRNG calls in private adapters. Host/origin checks run before upgrade;
private bootstrap data never enters HOST_INFO/assets/model. Static assets preload
with count/byte/path/symlink constraints. Windows wide command-line entry preserves
UTF-8 asset paths and resolves packaged UI beside the actual executable.
[ADR-020](../adr/ADR-020-local-browser-control.md) records access and recovery policy.

The packaged Svelte/TypeScript editor displays actual definitions, arbitrary
surfaces/triangulated geometry, logical source count, ownership and authored/
applied/saved statuses. Name editing, independent source placement, undo/redo,
observer updates, explicit reconnect and browser reload use validated commands.
Model types generate from the authoritative engine schema; exact integer/rational
strings are preserved. Browser pending work is bounded by count/bytes, captures
payload bytes at enqueue and retains one original in-flight request for same-service
replay. Unknown outcomes are not retried into expired/new services.

Foundation presets now build the editor, copy static assets/runtime notices/GPL
license beside the engine, and install them under bin/ui. Node/npm are build/test
tools; production HTTP serving is native C++. CI explicitly selects Node 24 and
the project wrapper installs development browser inputs and runs actual Chromium
tests. No blanket failure suppression or test quarantine was introduced.
[Editor commands and scope](../../ui/README.md); [locked source/notice inventory](../licenses/editor-dependencies.json).

Independent native clients test actual capability/origin denial, private bootstrap,
UTF-8 preloaded assets without rereading disk, lost-ACK replay, ownership/revision/
readonly/atomic parity, unavailable save, structural create/delete, subscription
recovery, duplicate JSON/binary refusal and control-hello deadline. Chromium runs
the packaged editor, deliberately drops one accepted ACK through a proxy and
observes `replayed=true`, then verifies edits/history/observer updates/placement/
reconnect/reload. A separate Vite server and its requested full reload preserve

Shutdown review also found member UDP buffers could reach destruction before

portable fixture now stops with clients still connected and requires normal exit;
no cancellation request is treated as completion and no drain timeout is weakened.

# M05 - Media library and baseline playback

Status: in progress. M04/M01 prerequisite qualification remains open. No tag.

## M05.C01 initial image-import slice

`libs/assets` builds a reusable image definition and sole-root-input binding as
one registry-validated transaction. It performs no IO/probe, preserves stage and
calibration, and supports undo and logical restoration of offline relative paths.
Independent placements still own separate instances. CLI `--image` uses that
transaction; a fresh project gets a native window and centred source layer fit.
Existing project routing/calibration stays authored. `--media-root` resolves
relative locators; its default is the initial-state directory or current directory.

The private Windows adapter uses actual Microsoft WIC PNG/JPEG CPU decode and
BCrypt SHA-256. IO, hashing, colour conversion, EXIF and eviction run on preparation.
Initial file sources render a placeholder while their first generation prepares;
native clock/output do not wait for IO. Images enter the existing native image/
graph handoff. Failed edits retain configuration and the last applied scene with
an image_* reason. No video or decoder acceleration is claimed.

Limits: 64 MiB encoded/file, 256 MiB read/request, 128 MiB canonical image payload/
request, 256 active image definitions, and a 64-entry/256 MiB content-hash cache.
Actual bytes are hashed before cache reuse, including same-path changes. Eviction
does not invalidate active immutable pixels. Reads use 64 KiB chunks; decode and
conversion use 64-row stripes, with cancellation between calls. The callback
cannot interrupt a current SDK/kernel call; the owned-process shutdown guard
remains. Payload limits exclude SDK/OS internals and are not measured memory.

Format baseline: static 8-bit RGB/RGBA/gray/indexed PNG and RGB/gray JPEG, converted
to linear premultiplied float pixels. Untagged SDR assumes sRGB; declared sRGB
and linear PNG gamma are recognized. Supported WIC colour contexts transform to
sRGB. Unsupported depth/gamma/animation/PNG EXIF/codec/profile modes remain errors.
JPEG EXIF 1-8 transforms pixels before publication. Microsoft vendor selection
is verified; no runtime is bundled. Long/unicode paths use private native syntax.
Layer fit/fill has a legacy stretch default and exact integer pixel-centre
sampling within the 16,384 dimension profile, independently of calibration.

Initial Debug CPU tests pass actual PNG alpha/colour/SHA-256, declared/linear
transfer, all eight JPEG orientations, long/unicode paths, cache invalidation/
eviction/retained ownership, cancellation and rejected requests. A real engine
quick import runs 120 frames with a hidden-window intermediate capture at maximum
1/255 against unchanged tolerance 2/255. Full Debug/Release evidence follows.
